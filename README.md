# Akan Name Generator
An application that takes a one's birthday and calculates their Ghananian name.
## Description
In Ghananian culture, children are often named after the day of the week they were are born. This project automates that tradition by inputting your birth dates and gender.
It uses a specific algorithm to determine the exact daay of the week you are born and your corresponding Akan name.
## Technology Used
* **HTML:** Structure of the webpage.
* **CSS:** Custom stylig and layout.
* **Javascript:** Core logic, form validation and calculation.
